# HydroFed

HydroFed is a local Python 3.11 research system for federated anomaly detection on hydropower-style telemetry.

The final system will support:

1. Synthetic or SKAB telemetry data
2. Non-IID partitioning across simulated hydropower plants
3. Local LSTM autoencoder training
4. Isolated baseline experiments
5. Flower-based federated learning with FedAvg
6. Evaluation with precision, recall, F1, and AUC-ROC
7. SQLite experiment storage
8. Prometheus metrics and Grafana dashboards
